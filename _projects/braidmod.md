**braidmod** uses machine learning to explore the reduced Burau representation of the four-strand braid group modulo a prime. The project uses Burau matrices and model confusion to probe the representation's kernel.

[Browse the source code and documentation on GitHub](https://github.com/caldermf/braidmod).
